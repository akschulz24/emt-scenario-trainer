# emt-scenario-trainer

A small, static EMT patient-assessment practice site. Choose a medical or trauma call, then interview and assess the simulated patient in a chat. Scene safety and a primary assessment gate patient information and vital signs.

## Run locally

Open `index.html` in a browser. The site has no build step, dependencies, or backend.

## Publish with GitHub Pages

1. Push this repository to GitHub.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.

The scenarios are educational practice only; follow local protocols and instructor guidance in real patient care.
